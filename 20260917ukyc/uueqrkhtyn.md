# 【世界阿尔茨海默病日】关爱老人 关注记忆

> 更新时间：2026-09-17 (UTC+8)

9月21日是第29个世界阿尔茨海默病日。今年主题为“知己知彼、早防早智——携手向未来” （Know Dementia, Know Alzheimer's——Together, we can do so much）。林忠荣主任做《老年痴呆，早预防、早受益》的主题讲座20日上午，我院神经内科二区在病房举办了专题健康宣教活动，旨在提升社会与家庭对阿尔茨海默病的关注度。神经内科主任林忠荣、二区执行主任徐锋平分别给病人和家属普及了阿尔茨海默病的筛查诊断、预防治疗与专业照护等健康知识，30余名患者及家属参加宣教活动。徐锋平主任做《老年人痴呆的识别和预防》讲座
阿尔茨海默病(简称AD)，俗称老年痴呆症，是多发于65岁以上老年人群中的一种神经退行性疾病，以记忆力减退为最主要的早期症状。

平均每三秒，世界上就会新增一名阿尔茨海默症患者，我国阿尔茨海默病患者约1000万人，是世界上患者人数最多的国家。

阿尔茨海默病的病因迄今不明，可能与遗传因素、神经递质、免疫因素和环境因素等有关。目前尚无特效治疗方法，主要为对症治疗，因此早预防、早诊断、早干预显得尤为重要。

**阿尔茨海默病的十大危险信号：**
- 
记忆力衰退(遗忘)

- 
难以完成熟悉的工作

- 
语言表达出现障碍

- 
搞不清时间和地点

- 
判断力受损

- 
理解力下降

- 
将物品错放在不恰当的地方

- 
情绪或行为的改变

- 
性格改变

- 
丧失兴趣和主动性

如果你的家人或身边的朋友有出现以上症状时，请一定提醒或带他们到医院就诊。阿尔茨海默病是一种慢性致命性脑病，患者的脑细胞不可逆地死亡，疾病的发展隐匿而平稳，病程从几年到几十年跨度较大。但是尽早识别、规范筛查、药物干预等措施可以极大程度地延缓痴呆的进展，因此，早防早治很关键。

呵护老人 爱是最好的药

**预防阿尔茨海默病主要要做到以下四点：**

**一是积极用脑，预防脑力衰退。**多看书看报、听音乐，进行益智活动，如打麻将、下棋等；

**二是适度运动。**坚持散步、打太极拳，做保健操或练气功，尽量多地活动手指，做一些复杂精巧的手工会促进脑的活力；

**三是保持情绪乐观。**多做些感兴趣的事及参加公益活动、社会活动等来强化脑部神经。

**四是饮食预防。**低盐饮食，蛋白质、食物纤维、维生素、矿物质等都要均衡摄取，少吃动物性脂肪及糖。

通过早期的预防措施，改变生活方式，可以减少老年人痴呆的风险。阿尔茨海默症患者脑海中的橡皮擦，会渐渐擦去他们人生的记忆。在记忆逐渐丢失的过程中，他们努力不去遗忘，也希望不被遗忘，让我们用知识、尊重、善意和帮助武装自己和我们身边的人，携手共克阿尔茨海默病的防治、康护难题。
