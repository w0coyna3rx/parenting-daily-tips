# 上海瑞金医院试管流程(瑞金试管和红房子试管)

> 更新时间：2026-09-19 (UTC+8)

**上海瑞金医院试管流程**

上海瑞金医院目前有开展二代试管婴儿，并没有开展三代试管，从同省开展该项技术的医院来看，三代试管婴儿和二代试管婴儿流程基本上是一样的，三代试管只是比二代试管多了一个胚胎筛查的环节，其他的术前检查、促排卵、取卵取精、胚胎培养、胚胎冷冻、试管移植都是一样的。一般在上海瑞金医院做二代试管仅需耗费1-2个月左右的时间，而三代试管则需要2-3个月左右的时间。

上海交通大学医学院附属瑞金医院已获得国家卫生部批准开展人类辅助生育技术资质，目前该院已开展了一代、二代试管婴儿技术，据了解上海瑞金医院试管婴儿成功率已达到50%以上，算是当地较为不错的试管婴儿医院。而在该院做二代试管与在其他医院做三代试管的流程具体如下：

1. 检查：进入试管周期之前要先检查身体，夫妻双方都要做；

2. 促排：通过注射药物，以获得多个成熟卵泡；

3. 取卵取精：打完夜针的第三天上午就会安排取卵了，同一天还会安排取精；

4. 培养培养：将精子卵子进行人工结合，然后培养到5-6天养成囊胚；

5. 筛查：这一步仅三代试管才会开展，将健康的囊胚筛查出来，以供移植；

6. 移植：筛查结果出来后会做个检查，如果身体条件允许就直接移植，不允许就冷冻囊胚等可以移植；

7. 验孕：在移植后第14天返院抽血检查hcg变化。

以上就是二代及三代试管婴儿流程介绍，目前上海瑞金医院仅支持二代试管，并不支持三代试管，有需要的患者可以去同市的上海一妇婴、上海同济医院、上海长征医院做。

**瑞金试管和红房子试管**

上海瑞金医院和红房子医院（上海集爱）试管技术都比较好，这两家医院目前都能够开展第一、二、三代试管婴儿技术，不过上海红房子医院开展三代试管技术更早，且全球首批成功应用“胚胎植入前单体型连锁分析”（简称“PGH”）试管婴儿就在复旦大学附属妇产科医院（上海市红房子妇产科医院）上海集爱遗传与不育诊疗中心出生。

上海交通大学医学院附属瑞金医院生殖医学中心是上海市最早获得开展人类辅助生殖技术资质的中心之一，而上海市红房子妇产科医院与美国遗传与辅助生育研究院于1997年合作组建的上海集爱遗传与不育诊疗中心为上海市第一家辅助生殖技术中心｡其实上海红房子试管就是指上海集爱试管，这里就为大家介绍一下上海瑞金医院和红房子医院试管相关情况：

一、上海瑞金医院

瑞金医院生殖医学中心是上海市最早获得开展人类辅助生殖技术资质的中心之一，主要诊治各种原因引起的不孕不育，中心成立至今已诞生数万名健康可爱的宝宝。瑞金医院生殖中心信息如下：

1. 开展技术：包括夫精/助孕人工授精、第一代/第二代和第三代试管婴儿、囊胚培养、胚胎玻璃化冷冻、卵子冷冻、稀少及单精子冷冻、卵母细胞体外成熟、供受卵试管婴儿、附睾/睾丸穿刺取精、睾丸显微镜下切开取精、多胎减胎术等；

2. 试管成功率：上海瑞金医院试管成功率处于国内先进水平，在50%左右；

3. 医疗团队：上海瑞金医院试管医生有徐步芳、牛志宏、陈骞等等。

二、上海红房子医院（上海集爱医院）

上海红房子医院生殖医学中心由中国科学院院士黄荷凤领衔创立，涵盖辅助生殖、生殖遗传、妇科内分泌、精子库、男科等专业领域，为不孕不育夫妇提供全方位的生育指导及助孕技术，为患家族遗传病、生育出生缺陷儿的家庭提供优生的遗传咨询服务。该生殖中心信息如下：

1. 开展技术：夫精人工授精、助孕人工授精技术、体外受精-胚胎移植、卵胞浆内单精子注入术、胚胎植入前遗传诊断、经皮睾丸/附睾精子抽吸术、胚胎冷冻复苏移植、辅助孵化技术及卵子冷冻技术，产前诊断､外周血及绒毛染色体检查等；

2. 试管成功率：上海红房子试管成功率也比较高，在50%-55%左右；

3. 医疗团队：临床医生21名，其中主任医师4名，副主任医师10名，比较出名的有黄荷凤、金丽、林仙华等等医生。

其实上海瑞金医院和红房子医院都是上海试管婴儿医院中比较知名的医院，试管技术都很成熟，医生经验也很丰富，试管收费也是透明合理的。因此，选择任何一家去做试管都可。
